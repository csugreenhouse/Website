Project Overview

Overview

This project focuses on the design of an automated greenhouse that uses image-based estimation to index each plant's information over time. Our long-term goal is to make the greenhouse responsive to the current states of the plants, fully autonomously.

Horticulture Department

We are in close collaboration with the CSU Horticulture Department, which currently uses a system that ignores valuable plant data and is reliant on manual labor. Our project aims to create a more efficient system and to non-invasively measure the plants, reducing the strain of maintaining a greenhouse.

Chemical and Biological Engineering

We are also in collaboration with Chemical and Biological engineering. The primary goal is to cultivate duckweed expediently as a high yield alternative protein source. The primary focus will be converting the current aquaponics system into a system that can support duckweed.

Highlighted Goals

The goal of this project this semester is to create an automated monitoring system to aid in the production of Poinsettias for the horticulture department. We are using image based metrics and OpenCV to determine the plant and growth.

Project Roadmap

Phase 1: Hardware and Power

  • Retrofit greenhouse trays for duckweed
  • Create the housings and mounts for both power and cameras
  • Build the solar and battery module

Phase 2: Imaging and Testing

  • Calibrate cameras in the Horticulture greenhoues
  • Create the housings and mounts for both power and cameras
  • Build the solar and battery module

Phase 3: Deployment and Delivery

  • Deliver the data to the Horticulture department.
  • Validate duckweed containment and harvesting with the CBE team.
